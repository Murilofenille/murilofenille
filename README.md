# 👨🏻‍💻 Murilo Fenille

**`Estudante de Tecnologia`**

Olá! Eu sou **Murilo Fenille**, estudante do Ensino Médio e apaixonado por tecnologia, programação, eletrônica e engenharia.

Gosto de aprender colocando as ideias em prática e, por isso, venho desenvolvendo meus próprios projetos para experimentar tecnologias, resolver problemas e entender melhor como o software funciona.

Atualmente, meu principal projeto é a **Kairo Education**, uma plataforma educacional que estou desenvolvendo do zero. Também desenvolvo ferramentas e projetos menores relacionados a programação, automação e eletrônica.

Meu objetivo com este GitHub é **registrar minha evolução, compartilhar meus projetos e construir meu portfólio para futuras oportunidades de estágio e trabalho na área de tecnologia**.

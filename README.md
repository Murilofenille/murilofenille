# 👨🏻‍💻 Murilo Fenille

**`Estudante de Tecnologia`**

Olá! Eu sou **Murilo Fenille**, estudante do ensino médio e apaixonado por tecnologia, programação, eletrônica e engenharia.

Atualmente, venho desenvolvendo projetos próprios para aprender na prática, explorando principalmente **desenvolvimento web, Python, bancos de dados, automação e sistemas embarcados**.

Um dos principais projetos que desenvolvo é a **Kairo Education**, uma plataforma educacional criada para transformar a forma como estudantes estudam e acompanham seu desempenho. Também trabalho em ferramentas próprias, como o **Kairo Question Engine (KQE)**, desenvolvido em Python para processamento e organização de questões de provas.

Meu objetivo aqui no GitHub é **documentar meus projetos, compartilhar o que estou aprendendo e construir um portfólio sólido para oportunidades de estágio e trabalho na área de tecnologia**.

### 📌 Projetos em destaque

#### 🎓 Kairo Education

Plataforma educacional voltada para estudantes, reunindo questões, simulados, resumos, conteúdos e ferramentas de estudo em um único ecossistema.

**Tecnologias:** desenvolvimento web, banco de dados, autenticação e infraestrutura em nuvem.

#### 🧠 Kairo Question Engine

Ferramenta desenvolvida em **Python** para processar provas em PDF, identificar questões e estruturar seu conteúdo para utilização na plataforma Kairo.

**Tecnologias:** Python, processamento de documentos e automação.

#### ⚡ Projetos de Eletrônica

Projetos experimentais utilizando **Arduino, sensores, LEDs, relés e outros componentes eletrônicos**, buscando integrar software e hardware.
